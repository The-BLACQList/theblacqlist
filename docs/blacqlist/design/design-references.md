## Current-standards note

Competent 2026 directory/marketplace products ship: photographic cards with designed fallbacks,
editorial rhythm in result grids (features/spotlights breaking the monotony), business pages that
read as destinations (immersive hero, in-page nav, offerings-first), quick-view without losing
context, dark-mode-aware token systems, and aggressive image pipelines (AVIF/WebP, focal points,
blur-up). A plain-pill category row and initials-avatars grid reads dated. Design to this bar.

## Tasteful-trend read (will-this-age test)

- **Documentary editorial + big type over real photography** — passes; it's a durable magazine
  tradition, not a fad, and it is *the* brand fit here. Use.
- **Bento/mixed-proportion grids** — passes when proportions encode editorial hierarchy (feature vs
  standard); fails when it's decoration. Use only where the doc's "publication, not marketplace
  template" intent applies (category grid, gallery mosaic).
- **Ambient node/particle backgrounds everywhere** — fails the aging test and the brand's own node
  discipline. The Q node is a signature accent, not wallpaper. Restrict per the direction doc.

## The genericness bar

If a page could belong to any directory product, it is not done. Every surface must carry at least
two of: real documentary photography, the gold-node signature used precisely, editorial type
hierarchy with intent, or the black/cream surface language.
